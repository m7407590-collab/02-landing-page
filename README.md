# Landing Page — Level 1, Task 2

A single-page marketing site for a fictional independent bookshop,
"Marginalia," built with plain HTML and CSS.

## Sections

- **Top bar** — brand mark and nav links
- **Hero** — headline, short pitch, and a call-to-action button
- **About** — shop story with a supporting photo
- **Shelves** — four category cards in an even grid
- **Events** — upcoming events list alongside a photo
- **Visit** — address and opening hours
- **Footer** — contact details

## Files

02-landing-page/
├── index.html
├── style.css
└── README.md

## How to use

1. Open `index.html` directly in a browser.
2. Swap the copy, images, address, and hours for your own business or idea.
3. All layout is done with CSS Grid and Flexbox — no framework required.

## Built with

- HTML5
- CSS3 (Grid, Flexbox, custom properties)
- Google Fonts: Fraunces, Source Sans 3

## Notes

Palette and type were chosen to fit a bookshop (warm paper tones, a
serif display face) rather than a generic template look. Fully
responsive, with the two-column sections stacking on narrower screens.
